# VibeResume 网申助手

一个无需构建即可使用的 Chrome / Edge Manifest V3 扩展。简历资料只保存在浏览器本地，扩展不会自动提交表单。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `extension/`。
4. 点击扩展图标，进入“编辑我的简历资料”并保存。
5. 打开网申页面，点击“填写当前页面”。

## 当前支持

- 姓名、电话、邮箱、性别、生日、地址等基本信息
- 目标岗位、薪资、到岗时间
- 求职状态、工作年限/性质、期望城市和行业
- 婚姻状况、国籍、户籍、证件类型、微信和 QQ
- 英语六级（CET-6）分数
- 民族、籍贯、政治面貌，以及其他英语考试成绩
- 可添加多段实习经历：公司、岗位、起止时间、工作内容
- 多段教育经历（本科、硕士、博士等）的学校、专业、各自的研究方向、起止时间、学历和 GPA
- 院校成绩排名、主修课程
- 多段项目、校园经历，以及语言、技能、证书和奖项资料
- 可选的多位家庭成员资料：与本人关系、姓名、电话、工作单位和职务
- GitHub、个人主页、领英
- 独立的自我介绍资料，可匹配自我评价、个人优势、个人陈述、职业概述等常见字段
- 原生输入框、文本域、下拉框，以及 React / Vue 常见受控文本输入
- 默认不覆盖网页上已经填写的内容
- JSON 格式的资料导入与导出
- 性别、婚姻、政治面貌、证件类型、求职状态、工作年限/性质、学历/学位、排名、语言和技能等级均提供下拉选项

## 限制与安全

- 招聘网站字段结构差异很大，自定义下拉框、级联地区、日期组件和工作/项目经历的动态列表需要按站点适配。
- 页面明确写有“本科”或“研究生”时会按学历匹配；只有重复的通用教育字段时，会按资料列表顺序填写。
- 浏览器禁止扩展静默选择本地文件，因此头像、证件和简历附件仍需手动上传。
- 扩展不会点击“提交”。自动填写后请检查敏感信息和所有字段。
