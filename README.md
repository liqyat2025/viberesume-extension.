# VibeResume 网申助手

VibeResume 网申助手是一个适用于 Chrome 和 Edge 的浏览器扩展。它在浏览器本地保存常用网申资料，并将资料自动填入常见招聘网站的表单。

扩展不会自动提交表单，填写完成后请逐项检查并手动提交。

## 下载

1. 在 GitHub 页面点击绿色的 **Code** 按钮。
2. 选择 **Download ZIP** 并解压。
3. 保留解压后的文件夹，安装扩展后不要删除或移动它。

## Chrome 安装方法

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后、内含 `manifest.json` 的文件夹。
5. 点击右上角的拼图图标，将“VibeResume 网申助手”固定到工具栏。

## Edge 安装方法

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择内含 `manifest.json` 的文件夹。
5. 将扩展固定到工具栏。

## 使用方法

### 录入资料

1. 点击浏览器工具栏上的 VibeResume 图标。
2. 点击“编辑我的简历资料”。
3. 填写需要重复使用的内容；不想保存的敏感信息可以留空。
4. 点击页面底部的“保存资料”。

### 填写网申页面

1. 打开招聘网站的申请表单。
2. 如果网页中有“添加教育经历”或“添加项目”按钮，先手动创建需要的条目数量。
3. 点击 VibeResume 图标，再点击“填写当前页面”。
4. 逐项检查姓名、证件号码、学历、日期和家庭信息。
5. 确认无误后再手动提交。

默认不会覆盖网页上已有的内容。如需覆盖，可在扩展弹窗中勾选“覆盖已有内容”。

## 支持的资料

- 基本信息：姓名、电话、邮箱、性别、生日、民族、籍贯、政治面貌、地址等
- 其他信息：婚姻状况、国籍、户籍、证件类型、微信和 QQ
- 求职信息：期望职位、薪资、城市、行业、求职状态、工作年限和工作性质
- 教育经历：多段学历、学校、专业、学位、研究方向、GPA、排名和主修课程
- 经历资料：多段实习、项目和校园经历
- 语言、技能、证书、奖项和荣誉
- 家庭成员：关系、姓名、电话、单位和职务
- 英语成绩、GitHub、个人主页、领英和自我介绍

## 资料备份

- 在资料设置页点击“导出备份”，可以生成 JSON 备份文件。
- 更换电脑或浏览器后，可使用“导入备份”恢复。
- 备份文件可能包含敏感信息，不要将它提交到 GitHub 或发送给他人。

## 隐私与安全

- 网申资料保存在当前浏览器的扩展本地存储中。
- 源码仓库不包含使用者填写的资料。
- 扩展不会自动提交表单。
- 身份证、家庭成员和地址等敏感信息可以留空。
- 不要将包含真实资料的 JSON 备份、截图或简历上传到公开仓库。

## 更新扩展

1. 重新下载并解压最新代码。
2. 用新文件覆盖原扩展文件夹。
3. 打开 `chrome://extensions/` 或 `edge://extensions/`。
4. 在 VibeResume 卡片上点击刷新按钮。

## 常见问题

### 点击填写后没有反应

- 确认当前页面是普通网页，而不是新标签页或浏览器设置页。
- 刷新招聘页面后再试。
- 确认已在资料设置页保存资料。

### 某些字段没有填写

招聘网站的表单差异较大。自定义下拉框、级联地区、弹出式日期控件和动态经历列表可能仍需要手动操作。

### 头像或简历附件没有上传

出于浏览器安全限制，扩展不能静默选择本地文件。头像、证件图片和简历附件需要手动上传。
